## ORGANIZAÇÃO DE PASTAS DO FRONTEND - RHSOFT
```
frontend/
├── assets/
│   ├── css
|   |   ├── global/              
|   |   |   └── global.css        # css que será utilizado em todas as paginas do site
|   |   └── pages/                # pasta que contém as pastas das paginas individuais
|   |       └── pagina/           # deverá ser criado uma pasta para cada pagina com seu respectivo .css
|   |           └── pagina.css
│   ├── images
|   |   ├── global/              
|   |   |   └── img               # imagens que serão utilizadas no site inteiro
|   |   └── pages/                # pasta que contém as pastas das paginas individuais
|   |       └── pagina/           # deverá ser criado uma pasta para cada pagina com seu respectivo .css
|   |           └── img
│   └── js
|       ├── global/              
|       |   └── global.js         # js que será utilizado em todas as paginas do site
|       └── pages/                # pasta que contém as pastas das paginas individuais
|           └── pagina/           # deverá ser criado uma pasta para cada pagina com seu respectivo .js
|               └── pagina.js
├── .html                         # todos os arquivos .html ficarão na raiz do diretorio
└── frontend.md                   # orientações sobre a organização das pastas
```
